---
name: search
description: Research a question on the web and report the answer with sources. Use for tool, library, API, or version questions that need current facts.
---

## Steps
1. Split the question into small, checkable parts.
2. Search for each part. Prefer official documentation, release notes, and source code.
3. Open the primary source. Do not rely on search snippets.
4. Compare at least two sources when they disagree or when the source is not official.
5. Write the answer.

## Output format
- **Answer**: 1 to 3 sentences.
- **Evidence**: one bullet for each claim. Add the URL and the source date.
- **Unverified**: list each claim that you could not confirm. Write "None" if all claims are confirmed.

## Rules
- Do not edit files.
- Do not guess. Write "unverified" instead.
- State the version that the answer applies to.
